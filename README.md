# TACA Tickets API

Proyecto ABP acumulativo del curso Programación con Node.js y APIs REST.

## Laboratorio base
- Node.js 24.21.0 LTS
- npm 11.19.0
- Puerto local: 3000

## Comandos
```powershell
npm start
npm run dev
```

## Comprobación inicial
- GET http://localhost:3000/health -> 200
- GET http://localhost:3000/no-existe -> 404
